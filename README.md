# SUWE

The Nigerian hopping game, for [start.ng](https://start.ng). Frontend only; the playable game lives in `docs/`.

- `docs/js/engine/` rules engine: pure, deterministic, no screen code
- `docs/js/render/` Canvas 2D drawing
- `tests/` engine tests (`npm test`), `tools/` local server and phone-size screenshots (not served)

Run: `npm run serve`, then open http://localhost:5173
